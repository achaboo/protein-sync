# protein-sync

その日の**食事内容**と**運動量**から一日の目標タンパク質を算出し、不足分を補うための
**ザバス ホエイプロテイン100（リッチショコラ味）**の必要量（スプーン杯数・摂取回数・摂取タイミング）を
自動計算するブラウザツールです。

`index.html` 1ファイルで完結します。サーバーも通信も不要で、ダブルクリックするだけで動作します。

---

## 公開URL

**https://achaboo.github.io/protein-sync/**

ブラウザで上記を開くとそのまま使えます。iPhone の Safari では、共有ボタンから
「ホーム画面に追加」しておくとアプリのように起動できます。

---

## 使い方

1. 上記URLを開くか、`index.html` をダブルクリックしてブラウザで開きます。
2. **① 基本設定** … 体重・基本係数・ザバスを溶かす液体を確認します。
3. **② 今日の食事** … 食べたもの（食べる予定のもの）の数量を入力します。
4. **③ 今日の運動** … 有酸素の距離を入力し、やらなかった筋トレ種目のチェックを外します。
5. **「計算する」** を押すと結果が表示されます。
6. 一度計算したあとは、**①〜③のどこを変更してもその場で自動再計算**されます。
   ボタンを押し直す必要はありません。更新されると結果が一瞬ハイライトされ、
   「④ 計算結果」の右上に最終更新時刻が表示されます。

入力内容はブラウザに自動保存され、次回開いたときに復元されます。
ただし **「② 今日の食事」はその日限りの入力**として扱われ、**日付が変わると 0 に戻ります**
（同じ日のうちに開き直した場合は入力し直さずに済むよう復元されます）。
体重・基本係数・液体の設定・筋トレの重量などは日付に関係なく保持されます。

- **「すべて 0 に戻す」**（②の見出し内）… 設定はそのままで、食事の入力だけをクリアします。
- **「入力をリセット」** … 確認ダイアログのあと、すべての入力が初期状態に戻り、保存内容も削除されます。

## 入力項目

### ① 基本設定

| 項目 | 初期値 | 説明 |
|---|---|---|
| 体重 | 75 kg | 目標タンパク質の算出基準 |
| 1日の食事回数 | 2食（朝食を抜く） | 配分先の食事枠を切り替える |
| 基本係数 | 1.5 g/kg | **運動しなかった日**の係数。運動した日はここに加算される |
| 溶かす液体 | 低脂肪乳 250ml | 液体のタンパク質も計算に加算される |
| ザバスで賄う上限 | 40 % | 目標のこの割合までを粉で補い、残りは食事に回す |
| 低脂肪乳を優先 | オン | オフにすると水も使って目標に最も近づく配分を選ぶ |

基本係数の目安（画面にも表として表示されます）:

| 入力値 | どんな人・どんな時期に選ぶか |
|---|---|
| 1.2 | 運動習慣がほぼない時期。医師からタンパク質制限を受けている場合 |
| 1.4 | 体重・筋肉量の維持が目的。食事量が多くない人はここから |
| **1.5**（初期値） | 週数回の筋トレを続けながら筋肉量を維持〜微増させたい標準的な設定 |
| 1.6〜1.7 | 減量中で筋肉を落としたくない時期、または筋肥大を狙う時期 |

液体のタンパク質量（100ml あたり）:

| 種類 | タンパク質 |
|---|---|
| 水 | 0 g |
| 低脂肪乳 | 3.8 g |
| 普通牛乳 | 3.3 g |
| 無調整豆乳 | 3.6 g |
| 調製豆乳 | 3.2 g |

### ② 今日の食事

| 食品 | 1単位あたり | 単位 | 配分される時間帯 |
|---|---|---|---|

| レトルトカレー＋ご飯1合 | 11 g | 食 | 昼・夕優先／ご飯もの／**1日3食まで** |
| 納豆 | 8.3 g | パック | 朝・夕優先 |
| 豆腐（1パック 150g） | 7.2 g | パック | 朝・夕優先 |

| ツナ缶 | 12.7 g | 缶 | 昼・夕優先 |
| サバ缶 | 16.7 g | 缶 | 夕・昼優先 |
| ギリシャヨーグルト | 25 g | 個 | 朝・夕優先 |
| ゆで卵 | 6 g | 個 | 朝優先 |
| 低脂肪乳（コップ1杯 200ml） | 5.7 g | 杯 | 朝優先 |
| ちくわ | 2.2 g | 本 | 昼・夕優先 |
| プロセスチーズ | 3.1 g | 個 | 朝優先 |
| みそ汁 | 1.4 g | 杯 | **昼食のみ**（固定） |
| コロッケ | 2.2 g | 個 | **昼食のみ**（固定） |
| 千切りキャベツ（150g 1袋） | 2.0 g | 袋 | 糖質メニューのある食事に優先配分 |
| その他（自由入力） | 手入力 | g | 10g 単位に分割して配分 |

低脂肪乳は「コップ1杯として飲んだ分」です。ザバスを溶かすのに使った分は別途
自動加算されるため、この欄には入れないでください。

千切りキャベツは血糖値対策（ベジファースト）のため、玉子丼やカレーなど糖質の多い食事がある
時間帯に優先して割り当てられ、その回では下線付きで先頭に表示されます。

**ご飯もの（玉子丼／レトルトカレー＋ご飯）は、1食につき1つまでしか配分されません。**
1度に2皿は食べられないためで、種類が同じでも異なっても重ねません。
入力した数が収まらない場合は、スケジュール表の下に「配分できませんでした」と警告が出ます
（その分も「食事から摂取」の合計には含まれます）。

食品によっては1日の入力上限を設けています（`FOODS` の `max`）。上限を超える値を入力しても自動で
切り詰められます。松のや 玉子丼は **1日1食まで**、レトルトカレー＋ご飯は **1日3食まで**です。

入力上限に収まっていても、食事回数によっては配分しきれないことがあります
（例：2食設定でカレー3食 → 2食分だけ配分し、残り1食分は警告）。

- **有酸素**: ウォーキング（km）／サイクリング（km）
- **筋トレ**: 6種目。**初期状態は全種目オン**。重量・回数・セット数は個別に変更できます。

| 種目 | 初期値 |
|---|---|
| ラットプルダウン | 25 kg / 15回 / 3セット |
| シーテッドローイング | 20 kg / 15回 / 3セット |
| チェストプレス | 20 kg / 15回 / 3セット |
| ショルダープレス | 10 kg / 15回 / 3セット |
| バイセップスカール | 10 kg / 15回 / 3セット |
| ディップス | 35 kg / 15回 / 3セット |

初期値どおり全種目実施すると総負荷量は 5,400 kg になります。

入力欄の初期値を変更した場合は `DEFAULTS_VER` を上げ、対象の入力欄を `RESET_IDS` に含めてください。
保存済みの値を復元せず新しい初期値を使うようになります
（体重・食事回数・ザバスの上限など、対象外の設定は保持されます）。

## 計算ロジック

### 1. 目標タンパク質

```
目標 = 体重 ×（基本係数 ＋ 運動による加算）     ※上限 1.8 g/kg
```

運動による加算は**下限の上書きではなく加算**です。基本係数を下げれば、運動した日の目標もその分下がります。

加算量は**運動量スコアに比例**します（段階判定ではないため、重量・回数・セット数・距離の変更が
そのまま結果に反映されます）。

```
運動量スコア = 総負荷量 ÷ 6,000kg ＋ ウォーキング換算距離 ÷ 10km   （上限 100%）
運動による加算 = 運動量スコア × 0.30
```

- 総負荷量 = Σ（重量 × 回数 × セット数）※チェックを入れた種目のみ
- サイクリングは同距離あたりの負荷が低いため、係数 0.35 でウォーキング換算します。

| 判定 | 加算 |
|---|---|
| 休養日 | ±0 |
| 軽運動日 | +0.01〜0.14 |
| トレーニング日 | +0.15〜0.24 |
| ハード日 | +0.25〜0.30 |

体重75kg・基本係数1.5 での例:

| 運動内容 | 総負荷量 | スコア | 係数 | 目標 |
|---|---|---|---|---|
| なし | 0 kg | 0% | 1.50 | 112.5 g |
| ウォーキング4kmのみ | 0 kg | 40% | 1.62 | 121.5 g |
| 筋トレ6種目（初期値） | 4,500 kg | 75% | 1.72 | 129 g |
| 初期値＋3種目を30kgに | 5,850 kg | 98% | 1.79 | 134.3 g |
| 初期値＋ウォーキング3km | 4,500 kg | 100% | 1.80 | 135 g |

スコアが100%に達すると係数は上限の1.8で頭打ちになり、それ以上運動を増やしても目標は変わりません。
その場合は「④ 計算結果」の根拠欄にその旨が明示されます。

### 3. 最低ライン

目標は「ここまで摂れれば理想」という上限であり、下回ったら失敗という線ではありません。
そのため「④ 計算結果」には目標とは別に **最低ライン（体重 × 1.2 g/kg）** を表示します。

- 最低ラインを超えていれば「この水準を保てていれば筋肉の維持には足ります」と表示
- 下回っている場合は、そこへ届かせるための不足量と食品の組み合わせを提示

タンパク質は1回に30〜40gしか使えないため、足りなかった分を翌日に取り返すことはできません。
評価は1日単位ではなく1週間の平均で見る前提の表示にしています。

### 4. 食事回数（2食 / 3食）

朝食を抜く習慣に対応しています。**2食（初期値）**では次のように動作します。

- 食事の配分先は**昼食と夕食のみ**（それぞれ50%ずつ）
- 朝食のみに固定された食品があれば**昼食に回されます**
- スケジュール表の朝食行は「朝食（抜く）」と表示し、前夜から昼まで間隔が空くため
  運動直後（または起床後）のザバスが実質的な朝の補給になる旨を案内します
- 「⑥ 食事・栄養のポイント」の分散に関する説明も2食向けの内容に切り替わります

### 5. 運動量に比例するのはエネルギー（糖質）

タンパク質の必要量は運動量に比例せず、体重×1.8g 程度で頭打ちになります。
一方で**エネルギーの必要量は運動量に比例して増える**ため、こちらは上限を設けずに算出し、
「⑥ 食事・栄養のポイント」に表示します。

```
推定消費 kcal = 総負荷量 × 0.04 ＋ 体重 ×（ウォーキングkm × 0.5 ＋ サイクリングkm × 0.28）
補う糖質 g   = 推定消費 kcal × 0.5 ÷ 4
```

エネルギーが不足すると、摂取したタンパク質がエネルギー源として使われ、筋肉の材料に回りません。

| 運動内容 | 総負荷量 | 目標タンパク質 | 推定消費 | 補う糖質 |
|---|---|---|---|---|
| 筋トレ6種目 3セット | 4,500 kg | 129 g | 180 kcal | 約23 g |
| 同 ＋ ウォーキング5km | 4,500 kg | 135 g | 368 kcal | 約46 g |
| 筋トレ6種目 12セット | 18,000 kg | 135 g（頭打ち） | 720 kcal | **約90 g** |

総負荷量が基準の2倍を超えた日は、回復に関する注意も表示されます。

### 2. 不足分とザバスの配分

```
不足 = 目標 − 食事からの合計タンパク質
```

不足を埋める配分は、次の制約の中から**不足量にいちばん近づく組み合わせ**を総当たりで選びます。

| 制約 | 値 |
|---|---|
| 1回あたりの吸収上限 | 40 g |
| 1回あたりの杯数 | 最大 4杯（推奨は3杯） |
| 1日の回数 | 最大 3回 |
| 2回以上に分ける場合の1回あたり最低杯数 | 2杯 |
| 許容する摂りすぎ | 3 g まで |

**液体のタンパク質も回数分だけ加算されます。**回ごとに水か低脂肪乳かを選べるため、
牛乳だと超過してしまう場合は一部の回を水に切り替えて目標に近づけます。
「低脂肪乳を優先」がオンのときは、目標とのズレが 1.5g 以内に収まる候補の中から
牛乳で溶かす回数が最も多いものを選びます。

**運動した日の1回目（運動直後）は水を優先します。**牛乳の脂質は胃の内容物の排出を遅らせるため、
運動直後は水のほうがアミノ酸が早く血中に届くからです。2回目以降（間食・就寝前）は
牛乳などの液体を優先します。運動していない日は1回目から液体を優先します。

ザバスで補いきれない分は「残り ○g は食事で補ってください」と明示され、
⑥ に具体的な食品の組み合わせが提案されます。**提案どおり追加すれば必ず指摘が消えます。**

あわせて「④ 計算結果」には、**提案どおりザバスを摂ったうえで、残りを食事で補う場合の早見表**を
表示します。各食品が単品で何個必要かを切り上げで示し、組み合わせる場合の例も添えます。
ザバスだけで不足が埋まる日は表示されません。

組み合わせ例は**栄養バランスを考慮**して選びます。食品を
**肉・魚・大豆・卵・乳製品**のカテゴリに分類し、その日すでに摂っているカテゴリを避けて、
まだ摂っていないタンパク源から優先して提案します（同条件ならタンパク質密度が高い順）。
同じ供給源に偏るとアミノ酸組成やビタミン・ミネラルが偏るためです。

残り50gの場合、②の入力内容によって提案が変わります:

| すでに摂っているもの | 提案 |
|---|---|
| なし | サラダチキン 1P ＋ サバ缶 1缶 ＋ ゆで卵 1個 |
| 肉 | ヨーグルト 1個 ＋ サバ缶 1缶 ＋ 納豆 1P |
| 肉・魚 | ヨーグルト 1個 ＋ 納豆 2P ＋ ゆで卵 2個 |
| 乳製品 | サラダチキン 1P ＋ サバ缶 1缶 ＋ ゆで卵 1個 |

選定理由も画面に表示されます（「今日すでに摂っている 乳製品 を避け、まだ摂っていない
タンパク源から優先して選んでいます」）。

**この組み合わせは1回だけ決定し、④の早見表と⑤のスケジュールで共有します。**
⑤では同じ品目が各食事に割り振られて「ここで追加：ツナ缶 1缶（12.7g）＋ ゆで卵 1個（6g）」
のように表示されるため、買い物する品目は④と⑤で必ず一致します。

```
④  残り43.3g → サラダチキン 1P ＋ ツナ缶 1缶 ＋ ゆで卵 1個
⑤  昼食：ここで追加 ツナ缶 1缶 ＋ ゆで卵 1個（+18.7g → 合計 40.1g）
    夕食：ここで追加 サラダチキン 1P（+30.3g → 合計 38.6g）
```

千切りキャベツ（血糖値対策の位置づけ）と、1単位 5g 未満の食品（ちくわ・チーズ・みそ汁・コロッケ）は
単品で補うと非現実的な数量になるため、早見表からは除外しています（組み合わせに加えるのは有効です）。

### ザバスで賄う上限

不足の全量を粉で補うと1日の大半をプロテインで摂ることになるため、
**ザバスで賄うのは1日の目標の一定割合まで**とし、残りは食事に回します。
割合は「① 基本設定」で変更でき、初期値は **40%** です（100%にすると不足の全量をザバスで補います）。

### 3. 時間帯別スケジュール

目標からザバス分を引いた残りを **朝30% / 昼35% / 夕35%**（1回40g上限）で配分し、
② で入力した食品を各食事に自動で割り当てます。ザバスは
**運動直後 → 15時頃の間食 → 就寝1時間前** の順に割り当てられます。

## 調整できる定数

数値を変えたい場合は `index.html` 内の該当箇所を書き換えてください。

| 定数 | 初期値 | 意味 |
|---|---|---|
| `SPOON_G` | 6.5 | スプーン1杯あたりのタンパク質 g |
| `PER_SERVE` | 3 | 推奨する1回あたりの杯数 |
| `MAX_PER_SERVE` | 4 | 1回に入れられる最大杯数 |
| `MAX_SESSIONS` | 3 | 1日に飲む最大回数 |
| `ABSORB_CAP` | 40 | 1回の摂取上限 g |
| `TOLERANCE` | 3 | 許容する摂りすぎ g |
| `MIN_PER_SERVE` | 2 | 複数回に分けるときの1回あたり最低杯数 |
| `MILK_SLACK` | 1.5 | 牛乳優先のために許容する目標とのズレの上乗せ g |
| `BONUS_MAX` | 0.30 | 運動による加算の上限 |
| `CAP_BASE` | 1.80 | 係数の上限 g/kg |
| `STRENGTH_FULL` | 6000 | この総負荷量(kg)で筋トレ側のスコアが100%になる |
| `CARDIO_FULL` | 10 | ウォーキング換算この距離(km)で有酸素側のスコアが100%になる |
| `FOODS` | — | 食品マスタ（タンパク質量・単位・配分する時間帯） |
| `LIQUIDS` | — | 液体マスタ（100ml あたりのタンパク質） |
| `EXERCISES` | — | 筋トレ種目と重量・回数・セット数の初期値 |

食品を追加する場合は `FOODS` に1行足すだけで、入力欄・計算・スケジュール配分すべてに反映されます。
時間帯を固定したい食品には `slots:['b'], lock:true, lockNote:'朝食のみ'` を指定します
（`b`=朝食 / `l`=昼食 / `d`=夕食）。

## 動作環境

- モダンブラウザ（PC / スマートフォン）。レスポンシブ対応。
- iOS Safari 向けに、フォーム部品の自前描画（チェックボックス・セレクト）、
  フォーカス時の自動ズーム防止（入力欄 16px 固定）、数値キーボードの `inputmode` 指定、
  ノッチ端末のセーフエリア対応を行っています。
- 外部ライブラリ・ネットワーク接続は不要です。ページを開いたあとはオフラインでも動作します。
- 入力内容は `localStorage`（キー `savas-calc-v3`）に保存されます。
  保存領域は**オリジン × ブラウザ × 端末**ごとに独立しており、自動同期は行いません。
  設定を別の端末へ移すには、「① 基本設定」の **「設定リンクをコピー」** を使います
  （URL の `#s=` に設定を埋め込むため、開いた端末にも保存されます。当日の食事・運動の入力は含みません）。
  Safari のプライベートブラウズでは保存されませんが、計算自体は正常に動作します。

## 注意

- 食品のタンパク質量は目安です。商品のリニューアル等で変わる場合は `FOODS` の値を修正してください。
- 本ツールは栄養管理の補助を目的としたもので、医学的な助言ではありません。
  腎機能に不安がある場合や持病がある場合は、医師・管理栄養士に相談してください。
