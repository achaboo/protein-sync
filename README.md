# Protein Sync
## 一日のたんぱく質 設計ツール

体重と**運動量**から一日の目標タンパク質を決め、その日の**献立・時間帯別の配分・食費**、
そして不足分を補う**SAVAS ホエイプロテイン100（リッチショコラ味）**の杯数までを
まとめて設計するブラウザツールです。目標を上回る日は、どの品目を減らすとよいかも提案します。

（リポジトリ名・公開URLは `protein-sync` のままです）

`index.html` 1ファイルで完結します。サーバーも通信も不要で、ダブルクリックするだけで動作します。

---

## 公開URL

**https://achaboo.github.io/protein-sync/**

ブラウザで上記を開くとそのまま使えます。iPhone の Safari では、共有ボタンから
「ホーム画面に追加」しておくとアプリのように起動できます。

## 使い方

1. 上記URLを開くか、`index.html` をダブルクリックしてブラウザで開きます。
2. **① 基本設定** … 体重・食事回数・基本係数を確認します。
3. **② 今日の食事** … 食べたもの（食べる予定のもの）の数量を入力します。
4. **③ 今日の運動** … 有酸素の距離を入力し、やらなかった筋トレ種目のチェックを外します。
5. **「計算する」** を押すと結果が表示されます。
6. 一度計算したあとは、**①〜③のどこを変更してもその場で自動再計算**されます。
   ボタンを押し直す必要はありません。更新されると結果が一瞬ハイライトされ、
   「④ 計算結果」の右上に最終更新時刻が表示されます。

### 画面の構成

- **タイトル行は画面上部に固定**されます。表示内容はスクロールしても変わりません。
- **①〜⑥は開閉式（アコーディオン）**です。見出しを押すとそのセクションだけが開き、
  **他は自動的に閉じます**。開いているセクションの見出しをもう一度押すと全部閉じ、
  **「① 基本設定」がタイトル行の下に来る位置まで戻ります**
  （畳んだ拍子に途中のセクションが画面上部に残らないようにするため）。
  「計算する」を押すと「④ 計算結果」が自動で開きます。
- 閉じているセクションの入力値もそのまま保持され、計算にも反映されます
  （表示を隠しているだけで、値は消えません）。
- 最後に開いていたセクションを記憶し、次回も同じ場所を開いた状態で始まります。
- **一度「計算する」を押していれば、次に開いたときも④〜⑥を表示したまま**始まります
  （`calculated` を保存内容に持たせています）。iOSはスリープ中にタブを破棄することがあり、
  戻るとページが読み込み直されるため、これがないと結果が消えたように見えます。
  復元のときはハイライト（flash）を出しません（`render({restore:true})`）。
  「入力をリセット」は保存内容ごと消すので、次回は計算前の状態に戻ります。

入力内容はブラウザに自動保存され、次回開いたときに復元されます。
**保存後に追加した食品**（保存データに存在しない品目）は、0のままにせずその日の型の数量を入れます。
ただし **「② 今日の食事」はその日限りの入力**として扱われ、**日付が変わると 0 に戻ります**
（同じ日のうちに開き直した場合は入力し直さずに済むよう復元されます）。
体重・基本係数・液体の設定・筋トレの重量などは日付に関係なく保持されます。

- **「食事をリセット」**（②の見出し内）… 設定はそのままで、食事の入力だけを初期状態（その日の曜日の固定メニュー）に戻します。
- **「入力をリセット」** … 確認ダイアログのあと、すべての入力が初期状態に戻り、保存内容も削除されます。

## 入力項目

### ① 基本設定

| 項目 | 初期値 | 説明 |
|---|---|---|
| 体重 | 73.5 kg | 目標タンパク質の算出基準 |
| 身長 | 177.4 cm | 基礎代謝（Mifflin-St Jeor式）の算出に使う |
| 年齢 | 55 | 同上 |
| 1日の食事回数 | 2食（朝食・夕食） | 昼食を抜く型。「昼食・夕食」「3食」も選べる |
| 基本係数 | 1.5 g/kg | **運動しなかった日**の係数。運動した日はここに加算される |
| SAVASで賄う上限 | 40 % | 目標のこの割合までを粉で補い、残りは食事に回す |
| 運動しなかった日もSAVASを摂る | オフ | オンにすると休養日も不足分をSAVASで補う（回復期向け） |
| SAVASの杯数を指定 | 空欄（自動） | 1〜4を入れるとその杯数に固定。食事を食べきれない日に粉を増やす用 |
| SAVASを1日2回まで摂る | オフ | オンにすると夕方に2回目を割り当てる（2食の日は自動で2回になります） |
| 夕食の時刻（③） | 18:00 | 夕食をこの時刻に置く。空欄なら基本の間隔で自動計算 |

基本係数の目安（画面にも表として表示されます）:

| 入力値 | どんな人・どんな時期に選ぶか |
|---|---|
| 1.2 | 運動習慣がほぼない時期。医師からタンパク質制限を受けている場合 |
| 1.4 | 体重・筋肉量の維持が目的。食事量が多くない人はここから |
| **1.5**（初期値） | 週数回の筋トレを続けながら筋肉量を維持〜微増させたい標準的な設定 |
| 1.6〜1.7 | 減量中で筋肉を落としたくない時期、または筋肥大を狙う時期 |

**SAVASは水300mlで溶かし、運動直後の1回だけ摂ります。**乳類は使わないため、液体からの
タンパク質の加算はありません。運動していない日はSAVASを摂らず、目標分はすべて食事から確保します。

**「SAVASの杯数を指定」**に 1〜4 を入れると、自動計算を上書きしてその杯数で組み立てます。
④には「杯数を手動で4杯に指定しています（自動計算では3杯）」と併記されるので、
自動計算の値は見失いません。空欄に戻せば自動計算に戻ります。
自動計算は不足量から決まり、**不足23g以上で4杯、それ未満は3杯**（筋トレをした日の最低杯数）です。
食事を食べきれない日に、その分を粉へ寄せたいときに使ってください。

**「SAVASを1日2回まで摂る」をオンにすると**、1回（最大4杯・26g）で埋まらない不足に対して
**夕方の2回目**を割り当てます。⑤には「2回目のSAVAS」の行が出て、時刻は夕食（回し分があればその後）から
さらに3時間後です。夕食を食べきれず、その分を粉に回したいときに使ってください。

なお「運動直後30分以内でなければ効果がない」というのは古い理解です。運動後に筋タンパク合成の
感受性が高まる状態は**数時間〜24時間程度続きます**。効果への寄与は
**①1日の総量 ＞ ②1回あたりの量と分散 ＞ ③タイミング** の順で、特に加齢に伴う同化抵抗性を考えると、
1回にまとめるより**確実に入る量を複数回に分ける**ほうが有利です。

**「運動しなかった日もSAVASを摂る」をオンにすると**、休養日も**不足があるときだけ**
起床後に1回摂る計算になります。筋トレをした日と違って最低杯数の縛りはないので、
食事だけで目標に届いていれば0杯です。オーバートレーニングからの回復期など、
運動量を落としてもタンパク質は落としたくない時期に使ってください。

配分される時間帯は品目ごとに決まっています（朝食のみ／夕食のみ／間食のみ など）。
詳しくは後述の「自宅の食材をどの枠に置くか」を参照してください。

その他には**テキスト欄**（`#otherNote`）を添えてあります。何を食べたかを書いておくと、
④の「食事の内訳」に「その他：ゆで卵2個・ヨーグルト1個（18g）」の形で出ます。
g数を入れずにメモだけ書いた場合は、②の合計欄に「計算には入っていません」と注意が出ます。
メモはその日限りの入力で、翌日と「食事をリセット」で消えます。

たんぱく質の下に**飽和脂肪酸・食塩相当量・炭水化物・食物繊維・エネルギー・価格**の欄があり、
分かる範囲だけ入れれば④の合計に加算されます（空欄は0として扱います）。栄養成分の内訳には
メモに書いた名前で並ぶので、何がどれだけ効いているかが分かります。たんぱく質だけ入れて
エネルギーが空のときは、②の合計欄で知らせます。

飽和脂肪酸（`sat`）は各社が公表している総脂質量に、日本食品標準成分表の脂肪酸比率を
当てて算出した推定値です。牛丼・豚丼・卵の多いメニューは総脂質の35〜40%、
親子丼は約29%、大豆（納豆）は約16%、サバは約26%が飽和脂肪酸にあたります。
ドレッシング（きざみ玉ねぎ・分離液状）は食用植物油脂が主体なので約11%とみています。
「その他（自由入力）」はタンパク質量しか分からないため合計に数えません。

たんぱく質と脂質は各社の公表値です。まぜのっけ朝食・得朝牛皿定食・ハムエッグ納豆定食の3品は、
当初は推定値を入れていましたが、公表値（17.1g／13.5g／24.1g）に差し替えました。

**食塩相当量**（`salt`）は外食メニューは各社の公表値、自宅の食材は商品ラベルの値です。
SAVASは1食分（28g）0.31〜0.76gと幅があるため、中間値の0.54g（1杯0.18g）で計算しています。
④に1日の合計を出し、成人男性の目標量 **7.5g未満**（`SALT_LIMIT`）を超えると警告枠を出します。
警告にはその日いちばん減らしやすいものを名指しします（みそ汁を外す／納豆のたれを使わない）。
外食メニューは1食2.3〜3.4gあり、朝夕とも外食の日は店のメニューだけで5g前後になります。

**炭水化物**（`carbG`）も各社の公表値です。FOODS には「糖質が多いメニュー」を示す真偽値の
`carb` が別にあるので、数値のほうは `carbG` という名前にしてあります（同名にすると上書きされます）。

**食物繊維**（`fiber`）は自宅の食材と SAVAS・納豆は商品ラベルの値ですが、
**外食メニューは各社が公表していない**ため、炭水化物からご飯の量を割り出し、具材（納豆・とろろ・
みそ汁など）を足した推定値です。丼もので4g前後、納豆の付く定食で7〜8gとみています。

**エネルギー**（`kcal`）は公表値です。1日の必要量は Mifflin-St Jeor 式の基礎代謝に
身体活動レベル I（1.50）を掛け、運動による消費を足して出します。座位中心の生活を前提にした係数で、
運動ぶんは二重に数えないよう別途加算しています。**入力した品目だけの合計**なので、
リストにないものを食べた日は実際の摂取はもっと多くなります。
過不足が100kcalを超える日は、体脂肪1kg＝7,200kcal として**週あたりの体重変化**も添えます。

**納豆のパック数は自動計算**です。目標から「固定メニュー＋卵＋トマトジュース＋サバ缶＋バナナ＋その他」と
SAVASを引いた残りを 8.3g で割り、四捨五入した数を入力欄に書き戻します。
切り上げではなく四捨五入なのは、切り上げると数g超過しやすいためです。
このため②の数量と④⑤の計算は常に一致します。

**手で書き換えると、その日は手入力が優先されます**（切らしている日は0や1にできます）。
手入力に切り替わると入力欄の下に「手入力に切り替えています」と表示され、
**「自動計算に戻す」ボタン**で元に戻せます。切り替えはその日限りで、翌日は自動計算に戻ります
（「食事をリセット」でも解除されます）。

**自動で数量が決まるのは納豆だけ**です。ほかの品目（固定メニュー・卵・トマトジュース・サバ缶・バナナ）は
その日の型が初期値として入るだけなので、いつでも手で書き換えられます。

トマトジュースは**食塩無添加**のものを前提にしています（例：Juver TOMATE 1L・スペイン産、
100mlあたり たんぱく質0.9g／食塩相当量0.03g）。カリウムを足してナトリウムとの比率を整える目的です。

**1日2杯（400ml）**にしているのは、1杯では目標量に届かないためです。この献立のカリウムは
1杯で約2,600mg（目安量2,500mgは満たすが、生活習慣病予防の目標量3,000mgに約400mg足りない）、
2杯で約3,100mgとなり目標量を超えます。食塩相当量は2杯でも0.12gで影響しません。

入力した数量に応じた**合計金額**を、「現在の食事合計：○g」の横に表示します
（「その他（自由入力）」は金額に含まれません）。

#### 夕食は外食3日・自宅4日

なか卯が自宅から4kmあり毎日通うのが負担なため、**親子丼を使っていた月・火・木・金の夕食を自宅**にしました。
すき家・松屋・吉野家に同等のメニューがないためです。親子丼はたんぱく質10gあたり150円と
外食メニューの中で群を抜いて効率がよく（次点のすき家 牛丼で198円）、450円以内でこれに並ぶ品は他店にありません。

自宅の夕食は**サバ缶1缶＋ご飯1.5合**（45.2g・367円）です。ご飯は0.5合の欄で3杯にしています。
丼をやめたぶんのエネルギー不足を埋めるための量で、親子丼（30g・450円）よりたんぱく質が多く、
飽和脂肪酸は4.4g対4.8gでわずかに少なく、116円安く済みます。
サバ缶は週3缶から**週4缶**になり、魚が週4回になりました。
サバ缶は缶のまま食べる前提です。マヨネーズ大さじ1で飽和脂肪酸が約1.4g増えますが、
④の合計には缶だけの4.2gを入れており、かけるものは含めていません。

**親子丼は `FOODS` に残してあります。**なか卯へ行ける日は手で 1 を入れてください。
その日は自動的に「外食の夕食の日」と判定され、サバ缶は間食へ戻ります。
ご飯は丼に付くので 0 にする必要があり、②の合計欄にその注意が出ます。

#### 自宅の食材をどの枠に置くか

自宅の食材は「外食に持ち込めない」ため間食の枠に固定していますが、
**その食事を自宅で摂る日にはこの前提が当てはまりません**。
そこで `homeMealDay(slot, st)`（その枠に自宅以外のメニューが入力されていない日）で判定し、
朝食と夕食のそれぞれについて置き場所を切り替えます。

| その日 | 朝食の枠へ | 夕食の枠へ | 間食に残る |
|---|---|---|---|
| 朝＝外食／夕＝自宅（月・火・木・金） | — | サバ缶・ご飯 | 納豆・卵・トマトジュース |
| 朝＝外食／夕＝外食（日・水・土） | — | — | 納豆・卵・トマトジュース・サバ缶 |
| 朝＝自宅／夕＝自宅 | ご飯・卵・納豆1P | サバ缶・ご飯 | 残りの納豆・トマトジュース |
| 朝＝自宅／夕＝外食 | ご飯・卵・納豆1P | — | 残りの納豆・トマトジュース・サバ缶 |

**間食を空にしない**のが設計の要点です。朝食10:00から夕食18:00まで8時間空くので、
自宅の食材を全部どちらかの食事に寄せると、その間がタンパク質の入らない時間になります。
そのため朝食へ回すのは `HOME_B_QUOTA`（卵2個・納豆1パックまで）とご飯だけで、
残りの納豆とトマトジュースは間食に置いたままにします。

朝食も自宅になる日は、**まぜのっけ朝食と同じ構成**（ご飯・卵・納豆）が朝食の枠に入ります。

|---|---|---|---|
| すき家 まぜのっけ朝食 | 15.0 g | 3.2 g | 300 円 |
| ご飯1.5合＋卵1個＋納豆1P | 27.8 g | 2.7 g | 158 円 |
| ご飯1.5合＋卵2個＋納豆1P | 33.8 g | 4.3 g | 185 円 |

卵はメニューに含まれる1個ぶんが無くなるので、その日は**2個まで**入れられます
（初期値は曜日の型から計算しているため自動では増えません。手で 2 と入れてください）。

ご飯は**自宅で摂る食事1回につき3杯（1.5合）**必要です（`riceNeed(st)`・`RICE_PER_MEAL`）。
朝夕とも自宅なら6杯で、足りなければ②の合計欄に「ご飯は ○ 杯必要です」と出ます。
入っていれば、丼にご飯が付くので0にするよう促します。

判定は配分（`distributeFoods`）とスケジュールの間食分の差し引き（`snackQty`）の
両方が同じ関数を見ているので、②の数量と④⑤の計算は常に一致します。

健診でLDLコレステロールの上昇と動脈硬化指数（AI 3.3）を指摘されたため、
飽和脂肪酸を減らす方向で型を組んでいます。

**朝食は飽和脂肪酸の最も少ないまぜのっけ朝食（3.2g）を基本**にしています。
ただし毎日同じでは飽きるので、**いちばん余裕のある木曜だけハムエッグ納豆定食（5.8g）**を
入れて変化をつけています（木曜は16.3gで目安の17gに収まります）。
得朝牛皿定食（9.0g）は牛が1食増えてしまうため型から外しました
（`FOODS` には残してあるので、手で入力すればいつでも食べられます）。
これで**牛肉は週2食**（日の牛丼、水の牛めし）になり、夕食は**鶏（親子丼）が週4回**、

吉野家の**塩さば得朝定食**（31.9g・6.9g・630円）も型には入れず、食材の一覧にだけ置いています。
朝食メニューで唯一たんぱく質が30gを超え、たんぱく質10gあたり197円と外食では牛丼に次いで

### 配分のルール

**運動直後はSAVAS（水300ml）とバナナ1本のみ。**運動した日はバナナを運動直後の枠に固定し、
他の食品は一切配分しません。糖質を入れることで、摂ったタンパク質がエネルギーに回されるのを防ぎます。
バナナは毎日2本が自動入力されます。運動していない日のバナナは通常どおり食事に配分されます。

**SAVASを2回に分ける日は、バナナも2回に振り分けます。**奇数のときは1回目を多くします
（3本なら 運動直後2本・2回目1本）。1回だけの日はすべて運動直後です。

**朝食メニューは朝食の枠、夕食メニューは夕食の枠にだけ**配分されます（`lock` 指定）。
曜日で固定しているメニュー（`fixedMenu`）は、④の早見表・組み合わせ提案・減らす提案の
いずれの対象にもしません。増減させる前提のものではないためです。

配分しきれない分があるときは、スケジュール表の下に「配分できませんでした」と警告が出ます
（その分も「食事から摂取」の合計には含まれます）。

食品ごとに1日の入力上限を設けることもできます（`FOODS` の `max`）。上限を超える値を入力すると
自動で切り詰められます。現在、上限を設定している食品はありません。

### ③ 今日の運動

- **運動を終える時刻**: 初期値 9:00。SAVASを飲む時刻として、⑤のスケジュールに実時刻を出すために使います
  （運動していない日はその日1食目の時刻として扱います）。日によって変わるので毎回確認してください。
  牛丼チェーンの**朝食メニューは11:00まで**しか注文できません。朝食はこの時刻の2時間後に置く計算なので、
  **運動を 9:00 までに終える**と間に合います。過ぎる日は⑤の朝食行に警告が出ます。
- **有酸素**: ウォーキング（km）／サイクリング（km）
- **筋トレ**: 8種目。**初期状態は全種目オン**。重量・回数・セット数は個別に変更できます。

| 種目 | 初期値 |
|---|---|
| ラットプルダウン | 25 kg / 15回 / 3セット |
| シーテッドローイング | 20 kg / 15回 / 3セット |
| チェストプレス | 20 kg / 15回 / 3セット |
| ショルダープレス | 10 kg / 15回 / 3セット |
| ディップス | 35 kg / 15回 / 3セット |
| バイセップスカール | 10 kg / 15回 / 3セット |
| サイドレイズ | 5.75 kg / 10回 / 3セット |
| リアレイズ | 5.75 kg / 5回 / 3セット |

重量は **RIR（Reps In Reserve）1〜2** ＝ 各セット終了時に「あと1〜2回できる」程度を基準に設定します
（この目安は画面上の筋トレ見出しの下にも表示されます）。

初期値どおり全種目実施すると総負荷量は 5,658.75 kg（運動量スコア 87%）になります。
重量欄は `step="any"` なので、5.75kg のような小数も入れられます。

入力欄の初期値を変更した場合は `DEFAULTS_VER` を上げ、対象の入力欄を `RESET_IDS` に含めてください。

次の更新のときに利用者が入力済みの値（体重など）まで初期値へ戻ってしまいます。
v10（サイドレイズ・リアレイズを5kg→5.75kgに変更）では筋トレの欄だけを対象にしています。

## 計算ロジック

### 1. 目標タンパク質

```
目標 = 体重 ×（基本係数 ＋ 運動による加算）     ※上限 1.8 g/kg
```

運動による加算は**下限の上書きではなく加算**です。基本係数を下げれば、運動した日の目標もその分下がります。

加算量は**運動量スコアに比例**します（段階判定ではないため、重量・回数・セット数・距離の変更が
そのまま結果に反映されます）。

```
運動量スコア = 総負荷量 ÷ 6,500kg ＋ ウォーキング換算距離 ÷ 10km   （上限 100%）
ウォーキング換算距離 = ウォーキングkm ＋ サイクリングkm × 0.35
運動による加算 = 運動量スコア × 0.30
```

- 総負荷量 = Σ（重量 × 回数 × セット数）※チェックを入れた種目のみ
- サイクリングは同距離あたりの負荷が低いため、係数 0.35 でウォーキング換算します。

| 判定 | 加算 |
|---|---|
| 休養日 | ±0 |
| 軽運動日 | +0.01〜0.14 |
| トレーニング日 | +0.15〜0.24 |
| ハード日 | +0.25〜0.30 |

体重73.5kg・基本係数1.5 での例:

| 運動内容 | 総負荷量 | スコア | 係数 | 目標 |
|---|---|---|---|---|
| なし | 0 kg | 0% | 1.50 | 110.3 g |
| ウォーキング4kmのみ | 0 kg | 40% | 1.62 | 119.1 g |
| 筋トレ3種目のみ | 2,925 kg | 45% | 1.64 | 120.5 g |
| 筋トレ8種目（初期値） | 5,658.75 kg | 87% | 1.76 | 129.4 g |
| 初期値＋ウォーキング2km | 5,658.75 kg | 100% | 1.80 | 132.3 g |

スコアが100%に達すると係数は上限の1.8で頭打ちになり、それ以上運動を増やしても目標は変わりません。
その場合は「④ 計算結果」の根拠欄にその旨が明示されます。

### 2. 最低ライン

目標は「ここまで摂れれば理想」という上限であり、下回ったら失敗という線ではありません。
そのため「④ 計算結果」には目標とは別に **最低ライン（体重 × 1.2 g/kg）** を表示します。

- 最低ラインを超えていれば「この水準を保てていれば筋肉の維持には足ります」と表示
- 下回っている場合は、そこへ届かせるための不足量と食品の組み合わせを提示

タンパク質は1回に30〜40gしか使えないため、足りなかった分を翌日に取り返すことはできません。
評価は1日単位ではなく1週間の平均で見る前提の表示にしています。

1食が30〜40gを超えた分は「⑤」で**回し分の行**に分け、**3時間空けて**摂るように組みます。
食後に高まった筋タンパク合成は3時間ほどで元に戻り、そこから次の一回が改めて効くためです。
2時間以内に続けて摂ると、まとめて食べたのとほとんど変わりません。
画面はこの理由を毎回は表示しません（表が読みにくくなるため）。理由はここに記載しています。

「⑥ 食事・栄養のポイント」は、**その日の状態 → 一般的な心得**の順に並べます。
先頭に最低ラインの判定、その次に過不足の状態（「食事の追加は不要です」「あと ○g を追加してください」
「○○を減らしてください」）と食事の入力漏れへの注意を置き、そのあとに①〜⑦の解説が続きます。

### 3. 食事回数（2食 / 3食）

「① 基本設定」で3つから選べます。

| 選択肢 | 抜く食事 | 配分 |
|---|---|---|
| **2食（朝食・夕食）**（初期値） | 昼食 | 朝50% / 夕50% |
| 2食（昼食・夕食） | 朝食 | 昼50% / 夕50% |
| 3食 | — | 朝30% / 昼35% / 夕35% |

- 抜く食事に固定された食品は、残っているもう一方の枠へ回されます
- スケジュール表には抜く食事の行が「昼食（抜く）」のように残り、間隔が空く旨を案内します
- 「⑥ 食事・栄養のポイント」の分散に関する説明も、選んだ型に合わせて切り替わります
- 昼食を抜く型では、朝食から夕食までの基本の間隔を8時間にしています

### 4. 運動量に比例するのはエネルギー（糖質）

タンパク質の必要量は運動量に比例せず、体重×1.8g 程度で頭打ちになります。
一方で**エネルギーの必要量は運動量に比例して増える**ため、こちらは上限を設けずに算出し、
「⑥ 食事・栄養のポイント」に表示します。

```
推定消費 kcal = 総負荷量 × 0.04 ＋ 体重 ×（ウォーキングkm × 0.5 ＋ サイクリングkm × 0.28）
補う糖質 g   = 推定消費 kcal × 0.5 ÷ 4
```

エネルギーが不足すると、摂取したタンパク質がエネルギー源として使われ、筋肉の材料に回りません。

| 運動内容 | 総負荷量 | 目標タンパク質 | 推定消費 | 補う糖質 |
|---|---|---|---|---|
| 筋トレ8種目 3セット（初期値） | 5,658.75 kg | 129.4 g | 226 kcal | 約28 g |
| 同 ＋ ウォーキング5km | 5,658.75 kg | 132.3 g | 410 kcal | 約51 g |
| 筋トレ8種目 12セット | 22,635 kg | 132.3 g（頭打ち） | 905 kcal | **約113 g** |

総負荷量が基準の2倍を超えた日は、回復に関する注意も表示されます。

### 5. 不足分とSAVASの配分

```
不足 = 目標 − 食事からの合計タンパク質
```

不足を埋める配分は、次の制約の中から**不足量にいちばん近づく組み合わせ**を総当たりで選びます。

| 制約 | 値 |
|---|---|
| 1回あたりの吸収上限 | 40 g |
| 1回あたりの杯数 | 最大 4杯（推奨は3杯） |
| 1日の回数 | **1回（運動直後のみ）**。「1日2回まで摂る」をオンにすると2回 |
| 許容する摂りすぎ | 3 g まで |

**SAVASは運動直後の1回だけ**なので、最大は 4杯（26g）です（5杯以上はメーカー推奨外）。水で溶かすため液体からの加算はなく、
脂質を含まないぶん胃を素早く通過してアミノ酸が早く血中に届きます。
**運動していない日はSAVASを摂りません**（目標分はすべて食事から確保します）。
①で「運動しなかった日もSAVASを摂る」をオンにした場合のみ、休養日も不足分を補います
（最低杯数の縛りはなく、不足がなければ0杯）。

### 2食の日はSAVASを8杯に固定

**2食（朝食・夕食／昼食・夕食）の日は、不足をまずSAVASで埋める**方針とし、
**上限の8杯（4杯×2回・52g）に固定**します。⑤には「運動直後」と「2回目のSAVAS」の2行が出ます。

- 判定に使うのは**自動計算した納豆を除いた不足量**です。納豆を足したあとに再計算しても
  杯数が動かないようにするためです（そうしないと「杯数が減る→納豆が増える→…」と堂々巡りになります）
- 納豆を除いた不足が52g未満の日は固定せず、自動計算のままにします（粉の摂りすぎを防ぐため）
- 「SAVASの杯数を指定」に入力があれば、そちらが優先されます
- 3食の日はこの固定を行いません

### 筋トレをした日はSAVASが必須

筋トレをした日は、**食事だけで目標に届いていてもSAVASを最低 3杯（19.5g）飲みます**
（`MIN_SPOONS_TRAINED`）。「SAVASの追加摂取は不要です」とは表示されません。

その結果、食事＋SAVASが目標を超える場合は、**食事のどれを減らすとよいかを提案します**。
減らす対象は、その日のタンパク源が多いカテゴリから、1単位あたりが大きいものを選びます。

ただし **現在は朝食・夕食とも曜日で固定した外食メニュー**（`fixedMenu`）で、
バナナ・トマトジュースとあわせて**すべて減らす提案の対象外**です。そのため超過した日は
「1単位が大きい品目しかないため、この日は多めのままで構いません」と表示されます。

目標とのズレが **5g 未満（`DEVIATION_OK`）は誤差として扱い、増やす提案も減らす提案もしません**。
増減で別のしきい値を使うと「減らせ」と「補え」が交互に出てしまうため、両方向でこの値を使います。

### 不足分の埋め方

不足は次の順で埋めます。

1. **SAVAS**（2食の日は8杯・52gに固定。それ以外は不足量から自動計算）
2. **納豆**（残りを 8.3g で割って四捨五入したパック数を自動入力）
3. それでも残る分は「残り ○g は食事で補ってください」と表示

納豆・卵・トマトジュース・バナナ・固定メニューはすべて**減らす提案の対象外**（自動計算または固定のため）
なので、数gの過不足はそのまま残ります。5g未満は誤差として扱うので、通常は指摘も出ません。

さらに増やしたい場合は、固定メニュー以外に食べたものを**「その他（自由入力）」**にg数で入れるか、
「SAVASで賄う上限」を上げてください。

④の早見表（各食品で残りを補う場合の数量と金額）には、次の制約をかけています。

- **自動計算する品目（納豆）は出しません。**数量が不足量から決まるため、そこへさらに足す提案は成り立ちません
- **1日の上限がある品目は、その日の残り枠まで**しか提案しません（卵をすでに1個食べていれば提案は1個まで）
- 提案しても不足が残る場合は「**これでも ○g 残ります**」と明示します
- 対象になる食品が1つも無い場合は、表そのものを案内文に置き換えます

食品を増やせるようにする場合は、`FOODS` に `fixedMenu` を付けない品目を足してください。
`SUGGEST_ORDER` は「固定メニュー・野菜・運動直後固定・自動計算でない、1単位5g以上の品目」から
自動で作られるので、追加した品目はそのまま提案・早見表に使われます。


### 6. SAVASで賄う上限

不足の全量を粉で補うと1日の大半をプロテインで摂ることになるため、
**SAVASで賄うのは1日の目標の一定割合まで**とし、残りは食事に回します。
割合は「① 基本設定」で変更でき、初期値は **40%** です（100%にすると不足の全量をSAVASで補います）。

### 7. 時間帯別スケジュール

目標からSAVAS分を引いた残りを **朝30% / 昼35% / 夕35%**（2食設定では 昼50% / 夕50%、
1回40g上限）で配分し、② で入力した食品を各食事に自動で割り当てます。
SAVASは運動直後の1回にまとめるため、間食・就寝前の行はありません。

#### 時間帯の見出しに出る「時刻・○時間後」

「③ 今日の運動」の **運動を終える時刻**（SAVASを飲む時刻。運動していない日はその日1食目の時刻）
を起点に、各食事の**実時刻**と直前の行からの間隔を見出しに表示します。
時刻を空欄にすると「○時間後」だけの表示になります。
抜く食事の行は「昼食（抜く）」のように残り、時刻は表示しません。

| 食事 | 基本の間隔 |
|---|---|
| 朝食 | 2時間後 |
| 昼食 | 3時間後 |
| 夕食 | 「夕食の時刻」を入れればその時刻。空欄なら4時間後（昼食を抜く型では8時間後） |

#### 夕食の時刻と「間食」

「③ 今日の運動」の **夕食の時刻**（初期値 18:00）を入れると、夕食をその時刻に置きます。
空欄なら基本の間隔（昼食を抜く型なら朝食の8時間後）で自動計算します。

iOS Safari の時刻ピッカーには「クリア」がなく、時刻欄を空欄に戻せません。
そのため注記の下に **「自動計算にする」ボタン**（`#clearDinner`）を置いています。
押すと欄が空欄になり自動計算へ切り替わります。ボタンは時刻が入っているときだけ表示します。
空欄の状態は保存され、設定リンク（#s=）でも他の端末へ運べます。

**納豆・卵・トマトジュースは外食に持ち込めない**ため、これらは朝食・夕食には配分せず、
**「間食」の行にまとめます**（`home` 指定・`slots:['s']`）。置く時刻は**いちばん間隔が空いている
食事どうしの中間**です。食後に高まった筋タンパク合成は3時間ほどで元に戻るため、
朝食と夕食の間の空白をこの間食が埋める形になります。

間食の分は**食事の目安量から差し引いて**から朝・夕へ配分するので、
朝食・夕食の「約○g」は外食メニューで摂る分だけを指します。

運動を9:00に終え、朝食11:00・夕食18:00とした火曜の例:

| 時刻 | 行 | 目安量 | 内容 |
|---|---|---|---|
| 9:00 | 運動直後 | SAVAS 4杯（26g） | ＋バナナ1本 |
| 11:00 | 朝食（2時間後） | 約21 g | すき家 まぜのっけ朝食 15g |
| **14:30** | **間食（自宅）** | **約36.8 g** | トマトジュース2杯 ＋ 納豆4P |
| — | 昼食（抜く） | — | 「上の間食がこの時間帯を埋めます」 |
| 18:00 | 夕食（7時間後） | 約21 g | なか卯 親子丼 30g |
| 21:00 | 2回目のSAVAS（3時間後） | SAVAS 4杯（26g） | |

**就寝前の注意は食品の行だけに出します。**回し分・間食が20:00以降になる場合は
「⚠ この時刻は就寝前にかかります」と警告しますが、**SAVASの行には警告を出しません**。
ホエイは吸収が速く脂質も少ない（1食2.0g）ため食事のような負担にならず、
就寝前のたんぱく質は睡眠中の修復に使われるからです。代わりに次の補足を添えます。

> 就寝前になりますが、ホエイは吸収が速く脂質も少ないので食事のような負担にはなりません。
> 睡眠中の修復に使われるため、この時刻でも問題ありません。
> 気になる場合は夕食の時刻を早めてください（この行も連動して早まります）。

なお2回目のSAVASを夕食にまとめることは勧めません。夕食（丼もの25〜30g）に26gを足すと
1回50g超になり、1回30〜40gの目安を大きく超えるためです。

**血糖値対策は「食前の難消化性デキストリン」に置き換えています。**自宅の野菜を持ち込めないため、
⑤の朝食・昼食・夕食の各行に「食事の前に難消化性デキストリンを。糖の吸収が穏やかになり、
丼もののご飯による血糖値の急上昇を抑えられます」と表示します。あわせて丼・定食のある食事には
「ご飯は最後に回す。みそ汁の具・卵・肉から先に食べるだけでも血糖値の急上昇は抑えられます」と出します。

#### 朝食メニューの注文期限（11:00）

牛丼チェーンの朝食メニューは11:00までです。その日の朝食枠に朝食メニューが入っている場合、
朝食の時刻が11:00を過ぎると⑤の朝食行に警告を出します。

> ⚠ 11:30 では朝食メニューを注文できません（11:00まで）。この配分どおりに摂るなら、
> 運動は 09:00 までに終える必要があります。間に合わないときは、先に朝食を済ませてから
> 運動してください（その場合はSAVASを朝食の2時間後に飲むことになります）。

間に合っている日も「いまの設定では 09:00 なので間に合います」と確認できるようにしています。
朝食を抜く型（2食「昼食・夕食」）では、この注記は出ません。

#### 回し分の行

1食が目安（1回40g上限）を超えている時間帯には、**「昼食の回し分」のような専用の行**を表に差し込みます。
時刻はその食事の3時間後、**次の食事はその回し分からさらに3時間後**です。こうするとすべての摂取が
3時間以上空きます。回し分が20時以降になる場合は、就寝前にかかる旨の注意を添えます。

回す品目は超過量にいちばん近い組み合わせを選びます。除外するのは次の3つです。

- **曜日で固定した外食メニュー**（`fixedMenu`。1食を分割できないため、その時間帯で摂る）
- **バナナ・トマトジュース**（時間帯を固定しているため）
- **その他（自由入力）**（中身が分からず単品として取り出せないため、朝食・昼食・夕食のいずれかで摂る）

**④で追加した品目を優先して回します**（もとの食事の形を崩さずに済むため）。
それで超過量に収まらない場合は、その食事に配分済みの品目も対象にします。
現在は固定メニューだけなので、超過した日は「回せる品目がありません」と表示されます。

**回した品目はもとの食事の行から差し引いて表示します。**同じものが2か所に出ていると
二重に食べてしまうためです。「ここで追加：〜」の行も、追加分を回した場合はもとの食事から消えます。
回し分の行には**品目と量だけ**を出し、理由（1回40gの上限、3時間空ける根拠、固定メニューを
残す理由）は表には書かずこのREADMEにまとめています。

7時に運動を終えた月曜の例（2食「朝食・夕食」・「SAVASを1日2回まで摂る」オン）:

| 時刻 | 行 | 目安量 |
|---|---|---|
| 7:00 | 運動直後 | SAVAS 4杯（26g）＋バナナ |
| 9:00 | 朝食（2時間後） | すき家 まぜのっけ朝食 15g |
| — | 昼食（抜く） | — |
| 17:00 | 夕食（8時間後） | なか卯 親子丼 30g |
| 20:00 | **2回目のSAVAS**（3時間後） | SAVAS 4杯（26g） |

昼食を抜く設定では朝食から夕食までの基本の間隔を **8時間** にしています（3食のときは4時間）。

## 動作環境

- モダンブラウザ（PC / スマートフォン）。レスポンシブ対応。
- iOS Safari 向けに、フォーム部品の自前描画（チェックボックス・セレクト）、
  フォーカス時の自動ズーム防止（入力欄 16px 固定）、数値キーボードの `inputmode` 指定、
  ノッチ端末のセーフエリア対応を行っています。
- 外部ライブラリ・ネットワーク接続は不要です。ページを開いたあとはオフラインでも動作します。
### 端末ごとに結果が違うとき

計算式は端末に依存しないため、結果が違う場合は**入力か表示中のバージョンのどちらかが違って**います。
「④ 計算結果」の根拠欄の先頭に、体重・食事回数・基本係数・SAVAS上限・バージョンを表示しているので、
2台の画面を見比べてください。

杯数は**不足量 23g を境に 3杯／4杯 が切り替わります**（体重73.5kg・基本係数1.5・2食の場合）。
型どおりの日は不足 32.6〜41.3g で4杯です。境界の近くでは、わずかな入力差でも杯数が変わります。

- 入力内容は `localStorage`（キー `savas-calc-v3`）に保存されます。
  保存領域は**オリジン × ブラウザ × 端末**ごとに独立しており、自動同期は行いません。
  設定を別の端末へ移すには、「① 基本設定」の **「設定リンクをコピー」** を使います
  （URL の `#s=` に画面の入力をすべて埋め込むため、開いた端末にも保存されます）。
  メモに日本語が入るため、`#s=` は UTF-8 に変換してから Base64 にしています
  （`btoa` は Latin1 しか扱えず、日本語をそのまま渡すと例外になります）。
  ASCIIだけの古いリンクは変換しても同じ文字列になるので、そのまま読めます。

  リンクは**ボタンを押した時点のスナップショット**です。押したあとに元の端末で値を変えても
  リンク側は変わりません。反映したいときは押し直して新しいリンクを配ります。
  リンクには作成日も入れてあり、**同じ日に開いた場合だけ食事・距離・実施種目まで復元**します。
  日付が変わってから開いたときは設定だけを反映し、食事はその日の型に戻します
  （食事は毎日入力し直す前提のため）。日付を持たない古いリンクも設定のみ反映します。
  Safari のプライベートブラウズでは保存されませんが、計算自体は正常に動作します。

## 注意

- 食品のタンパク質量は目安です。商品のリニューアル等で変わる場合は `FOODS` の値を修正してください。
- 本ツールは栄養管理の補助を目的としたもので、医学的な助言ではありません。
  腎機能に不安がある場合や持病がある場合は、医師・管理栄養士に相談してください。
- 初期値（体重・常用する食品・筋トレの重量など）は作者向けの設定です。
  公開リポジトリのため、この初期値は誰でも閲覧できます。自分用に使う場合は
  フォークするか、`index.html` の初期値を書き換えてください。
